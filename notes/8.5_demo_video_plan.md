# Milestone 8.5 - Demo Video Plan

## Goal

Prepare the recording script for a 3-5 minute PatchProof demo. The actual recording still has to be done manually with Loom, OBS, or another screen recorder.

## Demo script

1. Open the PatchProof repository and show a pull request with a meaningful code change.
2. Explain the core question: did this PR satisfy the original task, and is it safe to merge?
3. Trigger PatchProof from the GitHub App by opening or updating the PR.
4. Show the GitHub webhook delivery succeeding in the GitHub App settings.
5. Show the PatchProof PR comment with risk score, recommendation, evidence, requirement checks, and missing tests.
6. Open the React dashboard and show review history, detail view, filters, and risk trends.
7. Open VS Code, enter a task in the PatchProof sidebar, and run a local diff review through the backend.
8. Close with the architecture: GitHub/VS Code/CLI -> FastAPI -> review engine -> PostgreSQL -> dashboard/PR comment.
