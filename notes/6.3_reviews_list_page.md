# Milestone 6.3 - Reviews list page

## What changed

Milestone 6.3 replaces the placeholder frontend screen with a real reviews list page that fetches saved reviews from the backend.

The page calls:

```text
GET /reviews
```

It renders the response from milestone 6.1 as review cards.

## Files changed

- `frontend/src/api/client.ts`
  - Added TypeScript types for the reviews list response.
  - Added `fetchReviews()` using the existing Axios client.

- `frontend/src/App.tsx`
  - Replaced the scaffold placeholder with `ReviewsPage`.

## Files created

- `frontend/src/pages/ReviewsPage.tsx`
  - Fetches reviews on mount.
  - Tracks loading, ready, empty, and error states.
  - Shows total saved reviews and visible review count.
  - Renders review cards when data exists.
  - Shows the required empty state text:

```text
No reviews yet. Run patchproof review to get started.
```

  - Shows the required error state text:

```text
Failed to load reviews.
```

- `frontend/src/components/RiskBadge.tsx`
  - Green badge for low risk.
  - Yellow badge for medium risk.
  - Red badge for high risk.
  - Dark red badge for critical risk.
  - Gray fallback for unknown risk levels.

- `frontend/src/components/ReviewCard.tsx`
  - Displays repository name.
  - Displays risk badge.
  - Displays risk score.
  - Displays merge recommendation.
  - Displays created date.
