# Milestone 6.1 - Backend list endpoint

## What changed

Milestone 6.1 adds the read-only backend API that the React dashboard will use to show review history.

The new endpoint is:

```text
GET /reviews?page=1&limit=20&risk_level=high
```

It returns a paginated response with:

- `total`
- `reviews`
- each review's `review_id`
- `repo_name`
- `risk_score`
- `risk_level`
- `merge_recommendation`
- `created_at`

## Files changed

- `backend/api/reviews.py`
  - Added `GET /reviews` before `GET /reviews/{review_id}` so the list route is matched correctly.
  - Added pagination with `page` and `limit` query parameters.
  - Added optional `risk_level` filtering.
  - Returns newest reviews first.
  - Uses the linked repository to format `repo_name` as `owner/name`.

- `backend/schemas/review_schemas.py`
  - Added `ReviewListItemResponse`.
  - Added `ReviewListResponse`.

- `backend/main.py`
  - Added CORS middleware for the Vite dev server:

```text
http://localhost:5173
```

- `tests/integration/test_reviews_list_endpoint.py`
  - Added `httpx.AsyncClient` integration tests through the FastAPI ASGI app.
  - Covers successful list response.
  - Covers risk-level filtering.
  - Covers missing repository fallback.
  - Covers invalid pagination validation.
  - Covers CORS preflight from the Vite origin.

## Endpoint behavior

Default request:

```text
GET /reviews
```

Equivalent to:

```text
GET /reviews?page=1&limit=20
```

Filtered request:

```text
GET /reviews?page=1&limit=20&risk_level=high
```

Invalid pagination, such as `page=0`, returns FastAPI validation error `422`.
