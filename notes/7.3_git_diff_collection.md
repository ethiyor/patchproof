# Milestone 7.3 - Git Diff Collection via VS Code API

## What changed

- Added `vscode-extension/src/git/diffCollector.ts`.
- Uses VS Code's built-in Git extension API through `vscode.extensions.getExtension("vscode.git").exports.getAPI(1)`.
- Selects the repository for the active editor when possible, falling back to the first open Git repository.
- Calls `repository.diff()` to collect a unified working-tree diff.
- Handles three user-facing error cases: Git extension unavailable, no Git repository open, and no local changes.
- Wired the sidebar `Run PatchProof` button to collect the diff after task validation.
- The sidebar now reports the collected diff size as the Phase 7.3 verification signal.

## Why it matters

PatchProof's VS Code flow needs the same core input as the CLI and backend review path: a task description plus a unified Git diff. This milestone gives the extension the diff half of that contract without shelling out manually.

## Verification target

Open a Git repository in the Extension Development Host, make an uncommitted change, enter a task in the PatchProof sidebar, and click `Run PatchProof`. The sidebar should report that it collected a non-zero number of Git diff characters.
