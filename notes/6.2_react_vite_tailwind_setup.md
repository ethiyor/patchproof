# Milestone 6.2 - React + Vite + Tailwind setup

## What changed

Milestone 6.2 adds the first frontend application for the PatchProof dashboard.

The new frontend lives under:

```text
frontend/
```

It is a React + TypeScript app powered by Vite, styled with Tailwind CSS, and configured with an Axios API client that points at the PatchProof backend.

## Files created

- `frontend/package.json`
  - Adds Vite, React, TypeScript, Tailwind, PostCSS, Autoprefixer, and Axios.
  - Adds scripts:
    - `npm run dev`
    - `npm run build`
    - `npm run preview`

- `frontend/index.html`
  - Root HTML document for the Vite app.

- `frontend/vite.config.ts`
  - Configures React support.
  - Runs the dev server on port `5173`.

- `frontend/tsconfig.json`
  - TypeScript config for the React app.
  - Includes Vite client env types for `import.meta.env`.

- `frontend/tsconfig.node.json`
  - TypeScript config for Vite config files.

- `frontend/tailwind.config.ts`
  - Tailwind content scanning for `index.html` and `src/**/*`.
  - Adds a small PatchProof dashboard color extension.

- `frontend/postcss.config.js`
  - Connects Tailwind and Autoprefixer.

- `frontend/src/main.tsx`
  - React entrypoint.

- `frontend/src/App.tsx`
  - Placeholder dashboard screen.
  - Shows the configured backend API URL.

- `frontend/src/api/client.ts`
  - Exports an Axios client.
  - Uses `VITE_API_URL` when set.
  - Defaults to `http://localhost:8000`.

- `frontend/src/styles.css`
  - Tailwind base/components/utilities imports.
  - Global app font and body defaults.

- `frontend/src/vite-env.d.ts`
  - Vite type reference.

## Git ignore update

`.gitignore` now includes:

```text
node_modules/
```

The generated frontend dependency folder is not committed. The existing `dist/` ignore rule also keeps the Vite production build output out of git.

## How to run

From the frontend folder:

```text
cd frontend
npm run dev
```

The app runs at:

```text
http://localhost:5173
```

The backend API URL defaults to:

```text
http://localhost:8000
```

To point the dashboard somewhere else, set:

```text
VITE_API_URL=https://your-api.example.com
```
