# Milestone 8.3 - README and Documentation

## Goal

Make the repository understandable from a fresh clone and stop presenting PatchProof as only an early CLI project.

## What was changed

- Rewrote the top-level README around the current architecture.
- Documented the four product surfaces: CLI, FastAPI backend, GitHub App, dashboard, and VS Code extension.
- Added local setup instructions for the CLI and Docker Compose backend/database stack.
- Added key backend endpoints and a sample `POST /reviews/local` request.
- Added GitHub App webhook URL guidance for ngrok and AWS ALB deployments.
- Added VS Code extension setup and `patchproof.apiUrl` configuration.
- Added AWS deployment notes for ECR, ECS Fargate, ALB, RDS, IAM, and security groups.
- Removed the stale Phase 2/Phase 4 status table and outdated test notes.

## Why this matters

PatchProof now reads like a portfolio-grade system: a reviewer can see the problem, architecture, local setup, deployment path, and test commands without digging through the milestone docs first.
