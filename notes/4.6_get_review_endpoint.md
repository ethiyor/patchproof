# Milestone 4.6 - GET /reviews/{review_id} Endpoint

**Phase:** 4 | **Date:** 2026-07-06

## What was built

The backend can now retrieve a saved review by ID.

This completes the read side for reviews created by `POST /reviews/local` and
`POST /reviews/github-pr`: after a client creates a review and receives a
`review_id`, it can call `GET /reviews/{review_id}` to fetch the stored review
details from the database.

## Files changed

| File | Purpose |
|---|---|
| `backend/schemas/review_schemas.py` | Added `ReviewDetailResponse` plus nested finding, requirement check, and changed file response schemas |
| `backend/api/reviews.py` | Added `GET /reviews/{review_id}` with eager loading for related review rows |
| `tests/unit/test_reviews_api.py` | Added tests for successful detail retrieval and missing review `404` |

## Request flow

```text
GET /reviews/{review_id}
  -> validate review_id as UUID
  -> query Review by ID
  -> load ReviewFinding rows
  -> load RequirementCheck rows
  -> load ChangedFile rows
  -> return ReviewDetailResponse
```

## Response shape

The endpoint returns the saved review summary fields plus related detail lists:

- `review_id`
- `created_at`
- `task_text`
- `risk_score`
- `risk_level`
- `merge_recommendation`
- `report_markdown`
- `findings`
- `requirement_checks`
- `changed_files`

## Error handling

| Situation | Response |
|---|---|
| Review ID does not exist | `404` with `{"detail": "Review not found"}` |
| Review ID is not a UUID | FastAPI validation error |
