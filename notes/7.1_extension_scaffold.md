# Milestone 7.1 — VS Code Extension Scaffold

## What changed

- Added a new `vscode-extension/` package for the PatchProof VS Code extension.
- Registered the extension to activate on `onStartupFinished`.
- Added the `patchproof.reviewLocalChanges` command, which currently shows `PatchProof ready`.
- Added a PatchProof Activity Bar container and a `patchproof.sidebar` webview view.
- Added a minimal sidebar provider that renders a simple ready state.
- Added TypeScript config, VS Code package metadata, `.vscodeignore`, and a small Activity Bar SVG icon.

## Why it matters

This gives PatchProof a runnable editor-extension foundation. Later milestones can build on the command and sidebar to collect a task description, collect the current Git diff, call the PatchProof backend, and render the review report inside VS Code.

## Verification target

Open `vscode-extension/` in VS Code, run `npm install`, then press `F5` to launch the Extension Development Host. The PatchProof Activity Bar entry should appear, and `PatchProof: Review Local Changes` should show a `PatchProof ready` notification.
