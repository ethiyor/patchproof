# Milestone 8.1 - Unit Test Coverage

## Goal

Make sure the core PatchProof modules have local unit coverage and do not depend on real OpenAI or GitHub network calls during tests.

## What was done

- Verified the existing unit test suite for the CLI, backend helpers, database models, GitHub App helpers, webhook verifier, LLM models, report generator, diff parser, risk scorer, task analyzer, test checker, and verification engine.
- Added three additional sample diff fixtures so `tests/fixtures/sample_diffs/` now contains seven fixtures as requested by the Phase 8 plan.
- Added a parameterized parser smoke test that parses all seven sample diff fixtures.

## Fixture coverage

The seven sample diff fixtures now cover:

- Simple Python file addition.
- SQL migration and model change.
- Auth-sensitive backend change.
- GitHub PR-style diff.
- Frontend React component addition.
- Test-file addition.
- Secret-like configuration change.
