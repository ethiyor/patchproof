## Key concepts

- **`pyproject.toml`** — modern Python project config (PEP 517/518). `[project.scripts]` maps `patchproof` → `cli.main:app`.
- **Virtual environment** — isolated Python installation for this project.
- **Typer** — builds CLIs from function signatures. `typer.Option(...)` = required flag.
- **Editable install (`pip install -e .`)** — source changes take effect immediately.
- **`setuptools.build_meta`** — build backend; used instead of hatchling due to Python 3.14 editable install compatibility.
