# Milestone 8.2 - Integration Tests

## Goal

Verify backend API behavior through FastAPI test clients while avoiding real external API calls.

## What exists now

The integration suite currently verifies the reviews list endpoint and CORS behavior through `httpx.ASGITransport` against the FastAPI app:

- `GET /reviews` returns paginated review rows.
- `risk_level` filtering is accepted and applied.
- Reviews without a repository serialize with a safe fallback name.
- Invalid pagination returns validation errors.
- The Vite development origin is allowed by CORS.

## Validation

Run:

```bash
.venv/bin/python -m pytest tests/integration -q
```

Latest verified result:

```text
5 passed
```

## Remaining hardening

The Phase 8 plan also asks for full end-to-end tests for `POST /reviews/local`, `POST /github/webhook`, and `GET /reviews/{id}` with a real isolated PostgreSQL test database. Those are good next additions before calling the test phase fully production-grade.
