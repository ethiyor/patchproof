# Milestone 7.2 - Sidebar Panel + Task Input

## What changed

- Upgraded the PatchProof sidebar from a static ready message to an interactive Webview.
- Added a task text area labeled `Describe your task`.
- Added a `Run PatchProof` button.
- Enabled Webview scripts with a nonce-based content security policy.
- Added message passing from the Webview to the extension host using `vscode.postMessage`.
- Added extension-host handling for `{ type: "review", task }` messages.
- For this milestone, submitted tasks are logged to the extension host console and echoed back into the sidebar status area.

## Why it matters

This creates the interaction surface that later milestones need. Phase 7.3 can attach Git diff collection to the same button handler, and Phase 7.4 can replace the placeholder status response with a real backend review report.

## Verification target

Run the extension in the VS Code Extension Development Host, open the PatchProof Activity Bar view, enter a task, and click `Run PatchProof`. The sidebar should show `Task received: ...`, and the extension host console should log the submitted task text.
